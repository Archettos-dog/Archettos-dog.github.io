## 一、数学与机器学习基础

### 1.1 向量场（Vector Field）

向量场本质上是**向量到向量的映射**。在空间中每个点都有一个箭头，指示该点应往哪个方向走。

### 1.2 ODE（常微分方程）

最简单的速度方程即为 ODE，在后续 DDIM、Flow Matching 中会大量使用。

### 1.3 分布与采样

- 有一个分布 $P$
- 采样 = 按该分布的概率规律抽取一个具体样本

### 1.4 神经网络基础

- 输入 $X$ 经过参数 $\theta$ 决定的网络 $F_\theta(X)$，得到输出
- 定义损失函数（如 MSE）衡量输出质量
- 通过梯度下降更新权重

## 二、生成模型概述

### 2.1 基本思想

世界上存在真实数据分布 $P_{data}$（未知），但我们有一堆真实样本 $\{X_i\}$。我们希望通过神经网络学习一个近似分布 $P_\theta$，使其逼近 $P_{data}$。

**优化目标**：

$$\max_\theta \prod_i P_\theta(X_i) \quad \Rightarrow \quad \max_\theta \sum_i \log P_\theta(X_i)$$

（取对数避免数值下溢）

### 2.2 主流生成模型演进

- 2020 年之前：GAN 是主流
- 2020 年之后：基本被 Diffusion 取代（正面效果不如 Diffusion）
- VAE 虽非主流，但其思想在 Diffusion 中被大量使用

## 三、VAE 与 ELBO 推导

### 3.1 VAE 的设定

- 存在一个隐变量 $Z$（latent space）
- 生成过程：先从隐空间采样 $Z$，再根据 $Z$ 生成真实数据 $X$

### 3.2 两大难题

| 难题 | 说明 |
|------|------|
| **Inference** | 给定 $X$，如何得到 $Z$ 的后验分布 $P_\theta(Z \mid X)$？分母含积分，无法计算 |
| **Learning** | 如何调整 $\theta$ 最大化 $P_\theta(X)$？同样依赖积分 |

### 3.3 KL 散度

衡量两个分布的差异，**不对称**：

$$D_{KL}(P \| Q) = \mathbb{E}_{X \sim P}[\log P(X) - \log Q(X)]$$

### 3.4 引入 Encoder $Q_\phi$

用另一个网络 $Q_\phi(Z \mid X)$ 去近似真实后验。推导得到：

$$\log P_\theta(X) \geq \underbrace{\mathbb{E}_{Z \sim Q_\phi}[\log P_\theta(X \mid Z)] - D_{KL}(Q_\phi(Z \mid X) \| P(Z))}_{\mathcal{L} \text{ (ELBO)}}$$

**ELBO = Evidence Lower Bound（证据下界）**

### 3.5 ELBO 展开

- **重建项**：$\mathbb{E}_{Z \sim Q_\phi}[\log P_\theta(X \mid Z)]$，衡量重建好坏
- **正则项**：$D_{KL}(Q_\phi(Z \mid X) \| P(Z))$，希望隐空间不要太乱（KL 有闭合解）

### 3.6 VAE 训练流程

1. 取真实样本 $X$
2. 通过 encoder $Q_\phi$ 构造 $Z$
3. 通过 decoder $P_\theta$ 输出重建结果
4. 计算损失并更新参数

**生成时**：直接从隐空间采样 $Z$，再 decode 得到 $X$。

## 四、DDPM（Denoising Diffusion Probabilistic Models）

### 4.1 核心思想

> 给干净图像不断加噪→变成纯噪声；如果模型能学会去噪，那么反向从噪声出发就能生成真实图像。

### 4.2 前向加噪过程（Markov Chain）

每一步只依赖于上一步：

$$q(X_t \mid X_{t-1}) = \mathcal{N}(X_t; \sqrt{1-\beta_t} X_{t-1}, \beta_t \mathbf{I})$$

定义 $\alpha_t = 1 - \beta_t$，$\bar{\alpha}_t = \prod_{s=1}^t \alpha_s$。

### 4.3 前向过程的重要性质

通过递推合并高斯，可以**直接从 $X_0$ 跳到任意 $X_t$**：

$$q(X_t \mid X_0) = \mathcal{N}(X_t; \sqrt{\bar{\alpha}_t} X_0, (1-\bar{\alpha}_t)\mathbf{I})$$

### 4.4 反向过程

希望学习 $p_\theta(X_{t-1} \mid X_t)$ 逼近 $q$。但 $q$ 不可直接计算，**加条件 $X_0$ 后可以推导**。

假定反向过程也是高斯：

$$p_\theta(X_{t-1} \mid X_t, X_0) = \mathcal{N}(X_{t-1}; \mu_\theta(X_t, t), \beta_t \mathbf{I})$$

通过待定系数法解出：

$$\mu_\theta(X_t, t) = \frac{1}{\sqrt{\alpha_t}}\left(X_t - \frac{1-\alpha_t}{\sqrt{1-\bar{\alpha}_t}}\epsilon_\theta(X_t, t)\right)$$

### 4.5 损失函数推导

**负对数似然**：

$$-\log p_\theta(X_0)$$

**引入 ELBO 思想**（加一个非负 KL 散度），最终得到 VLB（Variational Lower Bound）：

$$L_{VLB} = L_T + L_{T-1} + \cdots + L_0$$

其中 $L_{t-1}$ 展开后是一个**带系数的 MSE**：

$$L_{t-1} = \mathbb{E}_{q}\left[\frac{1}{2\sigma_t^2}\|\tilde{\mu}_t(X_t, X_0) - \mu_\theta(X_t, t)\|^2\right]$$

**论文实验发现**：把所有系数都扔掉，直接预测噪声 $\epsilon$，效果更好：

$$L_{\text{simple}} = \mathbb{E}_{t, X_0, \epsilon}\left[\|\epsilon - \epsilon_\theta(X_t, t)\|^2\right]$$

### 4.6 训练 & 采样算法

**训练**：
1. 采样真实样本 $X_0$
2. 随机采样时间步 $t$
3. 随机采样噪声 $\epsilon \sim \mathcal{N}(0, I)$
4. 加噪得到 $X_t = \sqrt{\bar{\alpha}_t} X_0 + \sqrt{1-\bar{\alpha}_t} \epsilon$
5. 用 MSE 损失训练网络预测 $\epsilon$

**采样**：
- 从 $X_T \sim \mathcal{N}(0, I)$ 出发
- 一步步去噪：$X_T \to X_{T-1} \to \cdots \to X_0$
- 每步需要加一个随机噪声（不能只用一个期望）

## 五、DDIM（Denoising Diffusion Implicit Models）

### 5.1 动机

DDPM 需要 $T = 1000$ 步，太慢。能否跳步加速？

### 5.2 关键推导

从一步加噪公式反解 $X_0$：

$$X_0 = \frac{X_t - \sqrt{1-\bar{\alpha}_t}\,\epsilon_\theta(X_t, t)}{\sqrt{\bar{\alpha}_t}}$$

代入反向公式，可以**直接得到 $X_{t-1}$ 和 $X_t$ 的关系**。

### 5.3 DDIM 的核心创新

通过数学归纳法，可以实现**从任意 $X_T$ 到 $X_S$（$S < T$）的跳步采样**：

$$X_{S} = \sqrt{\bar{\alpha}_S}\underbrace{\frac{X_T - \sqrt{1-\bar{\alpha}_T}\,\epsilon_\theta(X_T, T)}{\sqrt{\bar{\alpha}_T}}}_{\text{预测的 } X_0} + \sqrt{1-\bar{\alpha}_S - \sigma_t^2}\,\epsilon_\theta(X_T, T) + \sigma_t \epsilon$$

**让 $\sigma_t = 0$**（即令 $C^2 = (1-\bar{\alpha}_{S-1})/(1-\bar{\alpha}_T)$ 的 $C=0$ 情形）→ 路径变确定 → 无需随机噪声 → 可以大步跳。

### 5.4 DDIM 的理论保证

- DDPM 的损失函数**只依赖从 0 到 T 一步，不依赖中间马尔可夫路径**
- 只要保证最终边缘分布相同，**不需要完整采用路径**
- DDIM 构建了**非马尔可夫**的联合分布
- 无论 $\sigma$ 取多少，都存在某个 $\gamma$ 使 DDIM 的损失函数可写成与 DDPM 相同形式
- 训练用同一套损失，采样可跳步

## 六、高阶视角：Score Matching 与 SDE

### 6.1 Score Function

对概率密度取梯度：

$$s(x) = \nabla_x \log p(x)$$

直观理解为**当前位置往哪走能让概率密度上升最快**——即"向量场上的小箭头"。

### 6.2 噪声与 Score 的关系

对加噪公式两边对 $X_t$ 取梯度，可得：

$$\nabla_{X_t} \log q(X_t) = -\frac{\epsilon}{\sqrt{1-\bar{\alpha}_t}}$$

> **本质**：学噪声 = 学 Score（只差一个负号和一个系数）

### 6.3 SDE 视角

- **前向过程**：$dX = f(X)dt + g(t)dW$（漂移项 + 扩散项）
- **反向过程**：依赖 Score
- 通过 Score 把这类生成过程统一建模

### 6.4 Probability Flow ODE

- 加噪：顺着 SDE 往前走
- 去噪：解反向 ODE（同样通过 Score）

### 6.5 可视化对比

- **DDPM**：路径较乱（每步加随机扰动），但最终都能收敛到 8 个点
- **DDIM**：路径光滑平整（确定性路径）

---

## 七、Flow Matching

既然 SDE 可以通过 Score 换算成速度，那**为什么不直接学速度**？

- $t=0$ 对应噪声分布，$t=1$ 对应数据分布
- 从数据集中取 $X_1$，从高斯取 $X_0$，构建差值
- 对差值关于 $t$ 求导即得**速度**
- 直接以速度为学习目标

求解过程即**解 ODE**。

## 八、扩散模型的高阶理解

| 视角 | 理解 |
|------|------|
| **噪声学习器** | 学噪声 → 算均值 → 得到上一步 |
| **Score 学习器** | 输出当前位置的梯度上升方向 |
| **ODE/SDE 求解** | 沿路径推演 |
| **分布搬运** | 把噪声分布搬到数据分布，构建最佳路径（非点到点，而是整个分布的映射） |

## 九、条件生成（Conditional Generation）

### 9.1 Classifier Guidance

- 训练一个分类器 $P(c \mid X)$
- 条件 Score：

$$\nabla_X \log P(X \mid c) = \nabla_X \log P(X) + \nabla_X \log P(c \mid X)$$

- 加上一个系数控制"听话程度"：

$$\hat{\epsilon} = \epsilon - \sqrt{1-\bar{\alpha}_t} \cdot \gamma \nabla_X \log P(c \mid X)$$

**缺点**：需要额外训练分类器。

### 9.2 Classifier-Free Guidance（CFG）

**核心思路**：不训练额外分类器。

将条件 Score 改写：

$$\nabla_X \log P(c \mid X) = \nabla_X \log P(X \mid c) - \nabla_X \log P(X)$$

**训练技巧**：训练时以一定概率**将条件丢掉**，让同一个模型同时具备：
- 有条件生成能力
- 无条件生成能力

推理时：

$$\hat{\epsilon} = (1 + w)\epsilon_\theta(X_t, t, c) - w\,\epsilon_\theta(X_t, t, \emptyset)$$

> CFG 的设计非常优美：一个模型同时做两件事。

## 十、采样加速方法

### 10.1 Progressive Distillation

- 老师模型需要 $N$ 步去噪
- 学生模型一步就学会老师两步的结果
- 重复蒸馏：步数 → $N/2$ → $N/4$ → $N/8$ → ...

### 10.2 Consistency Model

- 沿 ODE 求解路径，结果应一致
- 以**最终结果作为监督信号**，让中间一步与后续步骤学到的目标相同

### 10.3 DMD（Distribution Matching Distillation）

- 学生分布（fake）vs 老师分布（real）
- 目标：让两分布的差异尽可能小
- 对散度求梯度 = 两个 Score 差 + 跟生成器的梯度

**优势**：不是逐图像匹配（更鲁棒），而是分布级匹配。

## 十一、Diffusion 模型架构演进

### 11.1 U-Net（最朴素设计）

- 左侧：下采样（通道数变大，尺寸变小）
- 右侧：上采样
- Skip connection：保留原始信息
- 类似 ResNet/GoogLeNet 的 CNN 反复堆叠

### 11.2 LDM（Latent Diffusion Model）

**动机**：Pixel space 太大（如 $1.2 \times 10^9$），计算慢。

**设计**：
- 图像经 encoder 压缩到 latent 表示 $Z$（如 $64 \times 64$）
- 在 latent 上加噪、做 U-Net 预测噪声
- 训练完成后用 decoder 还原到像素空间

### 11.3 UNet + CLIP Text Encoder

- Text encoder 的设计与 CLIP 对齐
- 文本 embedding 与图像通过 cross-attention 融合
- 与 LDM 类似思路

### 11.4 Imagen

- 先从文本生成一个低分辨率小图片
- **级联（cascade）**地逐步提升分辨率
- **任务拆解思想**：第一步从隐空间读大致形状，后面再低分辨率到高分辨率

### 11.5 DiT（Diffusion Transformer）

- 抛弃 U-Net，用 Transformer
- 图片切成 patch，加 position embedding
- 条件（time、class label）通过 MLP 输出若干系数，用于 scale、shift
- 本质：把 Transformer 思路迁移到 Diffusion

### 11.6 MMDiT（多模态 DiT）/ SD3

- 同时处理文本和图像两种 context
- Text embedding 与 Image embedding 分别做 QKV 合并
- 注意力的输出再拆回两边
- 区分**长期目标 $Y$** 和**短期任务 $C$**
- 使用更多 encoder 编码 caption
- 工程上更复杂，但核心思想相同

## 十二、视频扩散模型

### 12.1 视频的特殊挑战

| 挑战 | 说明 |
|------|------|
| **时序一致性** | 相邻帧不能突变 |
| **计算成本** | 多一个时间维度，成本飙升 |

### 12.2 VDM（Video Diffusion Model）

- 3D = 2D 空间 + 1D 时间
- U-Net 同样下采样→上采样
- **时空分解（Spatial-Temporal Decoupling）**：
  - 时间层处理帧间关系
  - 空间层处理帧内信息
  - 分开后复杂度从 $O((FHW)^2)$ 降低到 $O((FHW) \cdot T)$
  - 同样能保证信息交换

### 12.3 Make-A-Video

- 文本 → 第一阶段 decoder → 几帧低帧率低分辨率视频
- 中间插入**frame interpolation（帧插值）**
- 再做高分辨率合成
- 整体思路：**任务拆解、难度分散**

### 12.4 Imagen Video / Video LDM

- 本质上是把图像上已 work 的 generator 迁移到视频
- 同样分离空间层与时间层

### 12.5 Sora（DiT-based 视频）

- 视频切成 **spatiotemporal patch**（时空 patch）
- 对时空 patch 做 attention
- 纯 DiT 结构

## 十三、Diffusion 前沿课题

### 13.1 双向 vs 自回归视频生成

| 类型 | 特点 |
|------|------|
| **双向视频生成** | 一次生成一批帧（如 1-10 帧同时出来），帧间可交换信息 |
| **自回归（AR）视频生成** | 基于历史逐步生成，才能生成真正长视频（流式） |

**Self-Forcing & CAS**：
- Self-Forcing：将双向老师蒸馏成单向 AR 模型
- 问题：训练时见的是真数据，生成时见的是自己生成的数据，存在错误偏移累积
- CAS：在 Self-Forcing 基础上，将双向老师先蒸馏为单向 AR 老师，再做初始化

### 13.2 Memory 与 Efficiency

- 矛盾统一体：Memory 越多，保留信息越多，但成本越大
- **LongLive**：流式生成，历史 token 逐步丢弃
- **Infinity**：在"丢"与"留"之间取平衡
- 本质是 **trade-off**

### 13.3 统一模型与世界模型

- **统一模型（如 Vision）**：用生成模型做理解任务
- **CoVLA**：同时具备生成、理解、动作能力
- **世界模型（World Action Model）**：
  - 联合训练动作与视频
  - 预测未来状态
  - 检验动作与未来状态是否相符

### 13.4 Diffusion 的其他迁移

| 应用 | 说明 |
|------|------|
| **Diffusion for RL** | 把去噪过程看作一次完整 RL rollout |
| **Diffusion Policy** | 在轨迹上做 Diffusion |
| **DPPO（Diffusion Policy Policy Optimization）** | 不是完全 IL，而是 self-distillation，老师在线纠正 |
| **Diffusion Forcing** | 把 token-by-token 生成改为扩散过程 |

> 2024 年 ICML 最佳论文颁给了探讨 DPO 的工作（黄楠老师组）。

### 13.5 其他重要方向

- 编辑模型（Editting）：只编辑图像局部
- 高分辨率生成
- 3D / 4D 生成与重建
- 更长视频生成
- 空间 Diffusion

## 十四、总结

Diffusion 模型在数学上有深刻背景（物理 + 信息论），是当前生成式 AI 的核心方法。从 DDPM → DDIM → Score Matching → SDE → Flow Matching，方法不断演进；架构上从 U-Net → LDM → DiT → MMDiT 持续进化；应用从图像扩展到视频、3D、机器人、生物合成等众多领域。
