# 学术交流技能 期末写作复习总结

## 一、格式（Format）

### 1. 商务信件 Business Letter

完整的信件包含以下部分（从上到下顺序）：

1. **Letterhead / Return Address**（信头/寄信人地址）
2. **Dateline**（日期）— 位于信头下方2行或页面顶部2英寸处
3. **Inside Address**（收信人地址）— 在日期下方2-10行
4. **Attention Line**（经办人，可选）
5. **Salutation**（称呼）— 如 Dear Mr. Wilson:
6. **Subject Line**（主题行，可选）— 在称呼下方2行，SUBJECT一词可省略
7. **Body**（正文）
8. **Complimentary Close**（结束语）— 如 Sincerely, 在正文末段下方2行
9. **Signature Block**（签名+职务）
10. **Reference Initials**（参考缩写）— 如 MHW:pil
11. **Enclosure Notation**（附件说明）— 如 Enc: (2)
12. **Copy Notation**（抄送说明）

两种排版样式：Block style（所有行左对齐）；Modified block style（日期和结束语从中间开始）。

### 2. 备忘录 Memo

结构分三部分：

**Title**：居中标题 MEMORANDUM

**Heading**（标题区，四行）：

- DATE:
- TO:
- FROM:
- SUBJECT:

**Body / Discussion**：通常分为

- Opening Segment（开头段，说明目的）
- Discussing Segment（讨论段，常用编号列表）
- Closing Segment（结尾段，提出要求/期限）

### 3. 电子邮件 Email

- **Subject**（主题）
- **Attachment**（附件，如有）
- **称呼**（如 Dr. Hong:）
- **正文**（说明情况 → 提出请求 → 礼貌结尾，如 Thank you.）
- **结束语 + 署名**（如 Regards, / Yeona Kim）

## 二、内容（Content）—各类报告应包含的要素

所有报告都遵循 **ABC 结构**：Abstract（摘要）→ Body（正文）→ Conclusion（结论）。

### 1. 摘要 Abstract（论文用，七要素）

1. Topic Specification (TS) 课题说明
2. Background Information (BI) 背景信息
3. Purpose Statement (PS) 目的陈述
4. Methodology and Data (MD) 方法与数据
5. Results/Findings and Discussion (RD) 结果与讨论
6. Conclusions/Implications (CI) 结论与启示
7. Key words 关键词（3-5个）

（MIC论文1500词，摘要150词）

### 2. 可行性报告 Feasibility Study（Memo格式）

ABC结构展开为：

- **Introductory Summary**（介绍性总结）：谁授权、为何目的、评估标准、推荐意见（要点前置）
- **Feasibility Criteria**（可行性标准）：通常含性能 Performance、预算 Budget、时间 Time Frame 等
- **Body**（正文）：逐条用标准衡量，从事实推向意见；评估单一项时讲优缺点，比较多项时按"逐项"或"逐标准"展开；可附加 Additional Benefits
- **Conclusion**（结论）：先结论后建议，三点以上用列表

要点：判断可行性（是否practical），客观呈现，用图表做比较，结尾可主动提出与读者会面。

### 3. 进度报告 Progress Report（Memo格式）

- **Introductory Summary**：项目背景、分几个阶段（Phases）、目前进展概述
- **Work Completed**（已完成工作）：按公司/任务/时间组织
- **Work Planned**（计划工作）：按时间排列（列出日期+任务），保证在期限内完成
- **Conclusion**：展望后续，强调价值，邀请读者反馈

### 4. 推荐报告 Recommendation Report（Letter格式）

- **Introductory Summary**：客户委托内容、初步结论与建议（开门见山）
- **Work at the Project Site**（项目现场工作）：日期、地点、任务
- **Laboratory Analysis / 各项分析**：方法 + 结果
- **Conclusions and Recommendations**：主要结论前置，用列表列出具体建议

### 5. 评估报告 Evaluation Report（Memo格式）

- **Introductory Summary**：背景、要评估的对象、总体结论
- **正文**（按被评估对象的各项功能分小节）：每段先讲最重要的点，再用具体例子/数据支撑
- **Conclusion**：重申要点（如 Versatility / Simplicity），提出后续意愿

------

## 三、答题要点提醒

考试形式是**格式 + 内容**，所以要做到：

写对外壳——根据题目要求选 letter / memo / email，把 Heading（DATE/TO/FROM/SUBJECT）或信件各部件写齐全；填对内容——根据报告类型填入对应的小标题段落（如可行性报告必有 Criteria + Conclusion，进度报告必有 Work Completed + Work Planned）。

通用写作逻辑都是：**开头说明目的 → 正文用标准/事实展开（多用编号列表）→ 结尾给结论/建议并表达后续意愿**。
