# 平稳过程谱分析期末大题参考

> 适用题型:出一道大题,要求验证平稳过程,计算均值函数、自相关函数;计算平均功率、谱密度。
> 
> 见沧海桑田，望白日飞升。走拙山枯水，笑月隐晦明。

---

## 一、解题套路总览

考试里这道题的考点高度固定,按 **"验证平稳 → 算均值/自相关 → 算平均功率/谱密度"** 四步走。

### 第一步:验证宽平稳(WSS)

只需要查两个条件(严平稳几乎不考验证,太麻烦):

- **条件一:** 均值 $\mu_X(t) = E[X_t]$ 是常数(与 $t$ 无关)
- **条件二:** 自相关 $R_X(t, t+\tau) = E[X_t X_{t+\tau}]$ 只依赖时间差 $\tau$,与 $t$ 无关

只要算出来这两个量、发现它们都不含 $t$,就下结论"故 $X_t$ 是宽平稳过程"。如果任何一个含 $t$,就是不平稳。

**最常考的载体:随机相位正弦波** $X_t = a\cos(\omega_0 t + \Theta)$,$\Theta \sim U(0, 2\pi)$。

这个例子必须背熟,几乎每年都考。关键是 $\Theta$ 在 $(0,2\pi)$ 上均匀分布,密度 $f(\theta) = \frac{1}{2\pi}$。

算均值:

$$\mu_X(t) = E[a\cos(\omega_0 t + \Theta)] = \int_0^{2\pi} a\cos(\omega_0 t + \theta)\cdot\frac{1}{2\pi}\,d\theta = 0$$

(整个周期上余弦积分为零,与 $t$ 无关 ✓)

算自相关(用积化和差是这步的核心技巧):

$$R_X(t, t+\tau) = E[a\cos(\omega_0 t + \Theta)\cdot a\cos(\omega_0(t+\tau) + \Theta)]$$

用公式 $\cos A \cos B = \frac{1}{2}[\cos(A-B) + \cos(A+B)]$:

$$= \frac{a^2}{2}E\big[\cos(\omega_0\tau) + \cos(2\omega_0 t + \omega_0\tau + 2\Theta)\big]$$

第一项 $\cos(\omega_0\tau)$ 是常数;第二项含 $2\Theta$,对 $\Theta$ 求期望时整周期积分为零。所以

$$R_X(\tau) = \frac{a^2}{2}\cos(\omega_0\tau)$$

只含 $\tau$ ✓ → **结论:$X_t$ 是宽平稳过程。**

记住这个结果 $R_X(\tau) = \frac{a^2}{2}\cos\omega_0\tau$,后面算谱密度直接用。

### 第二步:平均功率

公式只有一个,而且是送分的:

$$Q = R_X(0)$$

直接把 $\tau = 0$ 代入算出的自相关函数即可。比如上面的正弦波:$Q = \frac{a^2}{2}\cos(0) = \frac{a^2}{2}$。

(原理:平均功率那一长串极限推导,结论就是 $Q = R_X(0)$,考试不用推,记住结论。)

### 第三步:由 $R_X(\tau)$ 求谱密度 $S_X(\omega)$

维纳-辛钦定理正变换:

$$S_X(\omega) = \int_{-\infty}^{+\infty} R_X(\tau)e^{-i\omega\tau}\,d\tau$$

这步分两种情况,**取决于 $R_X(\tau)$ 是否绝对可积**:

#### 情况 A:指数型 $R_X(\tau) = Ae^{-\beta|\tau|}$(绝对可积,直接积分)

这是必背变换对:

$$Ae^{-\beta|\tau|} \;\longleftrightarrow\; \frac{2A\beta}{\beta^2 + \omega^2}$$

推导:拆成 $\tau<0$ 和 $\tau>0$ 两段积分

$$S_X(\omega) = \int_{-\infty}^0 Ae^{\beta\tau}e^{-i\omega\tau}d\tau + \int_0^{+\infty}Ae^{-\beta\tau}e^{-i\omega\tau}d\tau = A\left[\frac{1}{\beta-i\omega} + \frac{1}{\beta+i\omega}\right] = \frac{2A\beta}{\beta^2+\omega^2}$$

#### 情况 B:含直流/周期成分(不绝对可积,要用 $\delta$ 函数)

这时要用广义傅里叶变换的两个必背对:

$$1 \longleftrightarrow 2\pi\delta(\omega), \qquad \cos\omega_0\tau \longleftrightarrow \pi[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)]$$

接着上面正弦波的例子,$R_X(\tau) = \frac{a^2}{2}\cos\omega_0\tau$:

$$S_X(\omega) = \frac{a^2}{2}\cdot\pi[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)] = \frac{\pi a^2}{2}[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)]$$

> **判断技巧:** $R_X(\tau)$ 里只要出现 $\cos$、常数项,谱密度里一定有 $\delta$ 函数;只要是 $e^{-\beta|\tau|}$ 型衰减,就是有理分式、没有 $\delta$。

### 第四步(反过来):由 $S_X(\omega)$ 求 $R_X(\tau)$

考的是部分分式分解 + 反查变换对。

例:$S_X(\omega) = \dfrac{5}{\omega^4 + 13\omega^2 + 36}$

先因式分解分母:$\omega^4+13\omega^2+36 = (\omega^2+4)(\omega^2+9)$,然后部分分式:

$$S_X(\omega) = \frac{5}{(\omega^2+4)(\omega^2+9)} = \frac{1}{\omega^2+4} - \frac{1}{\omega^2+9}$$

**关键:把每一项凑成** $\frac{2A\beta}{\beta^2+\omega^2}$ **的样子来反查。**

- 第一项:$\frac{1}{\omega^2+4} = \frac{1}{\omega^2+2^2}$,所以 $\beta=2$。要凑出分子 $2A\beta = 2A\cdot 2 = 4A$,而现在分子是 1,故 $A = \frac{1}{4}$。对应 $\frac{1}{4}e^{-2|\tau|}$。
- 第二项:$\frac{1}{\omega^2+9}$,$\beta=3$,分子 $2A\cdot 3 = 6A = 1$,故 $A=\frac{1}{6}$。对应 $\frac{1}{6}e^{-3|\tau|}$。

利用线性性质:

$$R_X(\tau) = \frac{1}{4}e^{-2|\tau|} - \frac{1}{6}e^{-3|\tau|}$$

均方值(就是平均功率):$\Psi_X^2 = R_X(0) = \frac{1}{4} - \frac{1}{6} = \frac{1}{12}$。

## 三、综合模拟题(带完整解答)

> 这道题融合了"验证平稳 + 算均值/自相关 + 算平均功率/谱密度"四个考点,难度对标期末。建议先盖住解答自己做一遍,再对答案。

### 题目

设随机过程

$$X_t = A\cos(\omega_0 t + \Theta),\qquad t \in \mathbb{R}$$

其中 $\omega_0 > 0$ 为常数,$A$ 与 $\Theta$ 相互独立,$\Theta \sim U(0, 2\pi)$,$A$ 是均值为 $0$、方差为 $\sigma^2$ 的随机变量(即 $E[A]=0$,$E[A^2]=\sigma^2$)。

**(1)** 求 $X_t$ 的均值函数 $\mu_X(t)$;

**(2)** 求 $X_t$ 的自相关函数 $R_X(t, t+\tau)$,并判断 $X_t$ 是否为宽平稳过程;

**(3)** 求 $X_t$ 的平均功率 $Q$;

**(4)** 求 $X_t$ 的功率谱密度 $S_X(\omega)$。

> 这道题比基础原题多了一个"幅度也是随机变量"的设定,是常见的拔高方式,核心在于**用独立性把对 $A$ 和对 $\Theta$ 的期望拆开**。

### 完整解答

#### (1) 均值函数

$$\mu_X(t) = E[A\cos(\omega_0 t + \Theta)]$$

因为 $A$ 与 $\Theta$ 独立,期望可以拆开:

$$\mu_X(t) = E[A]\cdot E[\cos(\omega_0 t + \Theta)]$$

而 $E[A] = 0$,所以无论后一项是什么,都有

$$\mu_X(t) = 0$$

(与 $t$ 无关,满足宽平稳条件一。)

> 顺带也算一下后一项,第(2)问要用:
>
> $$E[\cos(\omega_0 t + \Theta)] = \int_0^{2\pi}\cos(\omega_0 t + \theta)\cdot\frac{1}{2\pi}\,d\theta = 0$$
>
> (余弦在一个完整周期上积分为零。)

#### (2) 自相关函数

$$R_X(t, t+\tau) = E[X_t X_{t+\tau}] = E\big[A\cos(\omega_0 t + \Theta)\cdot A\cos(\omega_0(t+\tau)+\Theta)\big]$$

把 $A^2$ 提出来,用独立性拆期望:

$$= E[A^2]\cdot E\big[\cos(\omega_0 t + \Theta)\cos(\omega_0(t+\tau)+\Theta)\big]$$

对后面那个乘积用**积化和差** $\cos\alpha\cos\beta = \frac{1}{2}[\cos(\alpha-\beta)+\cos(\alpha+\beta)]$,令 $\alpha = \omega_0 t + \Theta$、$\beta = \omega_0(t+\tau)+\Theta$:

- $\alpha - \beta = -\omega_0\tau$
- $\alpha + \beta = 2\omega_0 t + \omega_0\tau + 2\Theta$

所以

$$\cos\alpha\cos\beta = \frac{1}{2}\big[\cos(\omega_0\tau) + \cos(2\omega_0 t + \omega_0\tau + 2\Theta)\big]$$

(用了 $\cos(-\omega_0\tau)=\cos(\omega_0\tau)$。)

对 $\Theta$ 求期望:第一项 $\cos(\omega_0\tau)$ 是常数,期望还是它本身;第二项含 $2\Theta$,在 $(0,2\pi)$ 上整周期积分为零:

$$E\big[\cos\alpha\cos\beta\big] = \frac{1}{2}\cos(\omega_0\tau)$$

代回去,并用 $E[A^2] = \sigma^2$:

$$R_X(t,t+\tau) = \frac{\sigma^2}{2}\cos(\omega_0\tau) = R_X(\tau)$$

**判断:** 均值 $\mu_X(t)=0$ 为常数;自相关 $R_X(t,t+\tau)=\frac{\sigma^2}{2}\cos\omega_0\tau$ 只依赖时间差 $\tau$,与 $t$ 无关。又因 $E[X_t^2]=R_X(0)=\frac{\sigma^2}{2}<\infty$(二阶矩有限)。**故 $X_t$ 是宽平稳过程。**

#### (3) 平均功率

直接套 $Q = R_X(0)$:

$$Q = R_X(0) = \frac{\sigma^2}{2}\cos(0) = \frac{\sigma^2}{2}$$

#### (4) 功率谱密度

$R_X(\tau) = \frac{\sigma^2}{2}\cos\omega_0\tau$ 含余弦项、不绝对可积,要用 $\delta$ 函数。用必背变换对

$$\cos\omega_0\tau \;\longleftrightarrow\; \pi[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)]$$

由傅里叶变换线性性质:

$$S_X(\omega) = \frac{\sigma^2}{2}\cdot\pi[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)] = \frac{\pi\sigma^2}{2}\big[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)\big]$$

> **自检(可选,考场上有时间就验):** 用 $Q = \frac{1}{2\pi}\int_{-\infty}^{+\infty}S_X(\omega)\,d\omega$ 反推平均功率:
>
> $$\frac{1}{2\pi}\int_{-\infty}^{+\infty}\frac{\pi\sigma^2}{2}[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)]\,d\omega = \frac{1}{2\pi}\cdot\frac{\pi\sigma^2}{2}\cdot 2 = \frac{\sigma^2}{2}$$
>
> 和第(3)问一致 ✓。这一步能帮你检验 $\delta$ 前面的系数有没有算错。

### 这道题的几个易错点

- 第(1)(2)问的关键是**独立性拆期望**:$E[A\cdot g(\Theta)] = E[A]E[g(\Theta)]$、$E[A^2 g(\Theta)] = E[A^2]E[g(\Theta)]$。如果题目改成"$A$ 是常数 $a$",那就是基础原题,$E[A^2]$ 换成 $a^2$,结果里 $\sigma^2$ 全换成 $a^2$——可以拿这个当变式自测。
- 另一个高频坑:积化和差后的第二项 $\cos(2\omega_0 t + \cdots + 2\Theta)$,**含 $2\Theta$ 才会积分为零**;如果是对 $t$ 求时间平均也为零,但本题是对随机变量 $\Theta$ 求期望,务必写清楚"对 $\Theta$ 在 $(0,2\pi)$ 上整周期积分为零",别省这句,阅卷给步骤分。
