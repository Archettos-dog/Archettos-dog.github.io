> **用法说明**：案例是这门课的"硬通货"——每引一个案例就多一个得分锚点。
> 每张卡片四栏：**案名 → 一句话事实 → 证明的命题 (holding/principle) → 可用于哪道题**。
> 考前按主题块过一遍；考场上每个论点尽量挂一个案例。
> **加分动作**：不要只写"如某案所示"，要写"该案确立了……规则，本案事实与之类似/不同，因为……"。

# 主题块 A · 著作权独创性与思想/表达 (Originality & Idea/Expression)

## A1. 红色巴士案 (Iconic London Red Bus)｜英

| | |
|:---|:---|
| **事实** | Fielder 拍伦敦红色巴士照，再用 Photoshop 强化红色、抠掉天空、转单色、移走行人、拉透视，耗约 80 小时。被告作了相似的红巴士黑白图。 |
| **命题** | 大量创作选择（构图、修图、安排）使作品具**独创性**；争点是被告取的是**思想**还是**实质性表达**。 |
| **用于** | Q1（独创性判断）、Q2(a)（思想/表达二分）、任何"是否受版权保护"的分析。 |

## A2. Harry Potter v. Tanya Grotter｜俄/荷

| | |
|:---|:---|
| **事实** | 俄语作品 Tanya Grotter 被指抄袭哈利波特。字面表达（俄语 vs 英语）明显未抄。 |
| **命题** | 字面表达未抄时，争点转向**非字面表达 (non-literal / SSO：结构、顺序、编排)** 是否被抄。 |
| **用于** | Q2（区分字面 vs 非字面表达）、AI 输出"实质性相似"分析。 |

## A3. Picasso 立体主义风格 (Cubism Style)

| | |
|:---|:---|
| **事实** | 他人以立体主义风格画三女像。 |
| **命题** | **风格本身不受保护**——他人可用同种风格创作，只要不抄**具体表达**。表达 = 构图+内容+风格+色彩+叙事的**总和**，单取风格不足。 |
| **用于** | Q2(c)（输出仅"模仿风格"vs 抄表达）、AI 生成"in the style of"分析。 |

## A4. 电话簿白页 (Phone Directory White Pages)

| | |
|:---|:---|
| **事实** | 电话簿白页按字母顺序排列，投入大量劳动收集。 |
| **命题** | **纯事实不受保护**；有劳动投入但**无创造性** → 不可版权（劳动≠独创性）。 |
| **用于** | Q2(a)（独创性的"最低创造性"要件）、反驳"我花了很多功夫所以受保护"。 |

## A5. 人头马广告语 / 证件照对比 (易错点组)

| | |
|:---|:---|
| **事实** | "人头马一开，好事自然来"广告语被认定足够独创；护照证件照因无创作自由→不受保护；Mankowitz 拍 Jimi Hendrix 肖像（指导姿势、选灯光角度）→受保护。 |
| **命题** | 短语/小作品**一般难**受保护但**个案判断**；关键看是否有**创作自由与选择**。 |
| **用于** | Q1/Q2 独创性的边界判断、易错点举例。 |

# 主题块 B · AI 训练数据与侵权 (AI Training & Infringement)

## B1. NYT v. OpenAI｜美 ★核心案

| | |
|:---|:---|
| **事实** | ① OpenAI 将 NYT 文章复制入训练集；② 训练后模型可**逐字 (verbatim)** 复现 NYT 内容。 |
| **命题** | **输入端**：复制入训练集 = 未经许可复制 vs OpenAI 抗辩转换性合理使用；**输出端**：逐字复现 = 实质性相似。OpenAI 称原告"提示词攻击"诱导、模型"不记忆"。 |
| **用于** | Q2(b)（训练是否侵权）、Q2(c)（输出实质性相似）。**输入/输出必须分开讲。** |

## B2. Getty Images v. Stability AI (2023)｜英/美

| | |
|:---|:---|
| **事实** | 未经许可用约 **1200 万张** Getty 图训练 Stable Diffusion；模型可复现 Getty **水印**与风格。 |
| **命题** | 诉由 = 版权 + **商标**（复现水印）+ 不正当竞争。水印复现是"记忆与复吐"的有力证据。 |
| **用于** | Q2（训练侵权 + 输出证据）、说明侵权可叠加商标问题。 |

## B3. Ultraman 奥特曼案 (广州互联网法院)｜中 ★重点判例

| | |
|:---|:---|
| **事实** | SCLA 经 Tsuburaya 授权享奥特曼专有权。被告网站经提示("generate an Ultraman Dyna")生成图与奥特曼部分/完全相似。 |
| **命题** | 奥特曼为原创美术作品受保护；AI 生成图**同时侵犯复制权（复制原画）与改编权（未经许可修改）**。中国少有的 AI 输出侵权判决。 |
| **用于** | Q2(c)（输出侵权的中国法应用）、AI 服务商责任。 |

## B4. Authors Guild v. Google (2d Cir. 2015)｜美 ★Fair Use 标杆

| | |
|:---|:---|
| **事实** | Google 扫描数百万本书建可搜索库，仅显示**片段 (snippets)**。 |
| **命题** | **高度转换性**（变为搜索工具）、非市场替代 → **属合理使用**。规则：即使整本复制，只要转换且不损害市场亦可。 |
| **用于** | Q2(b)（fair use 四要素，尤其要素 1 转换性 + 要素 4 市场影响）、类比 AI 训练抗辩。 |

## B5. Andersen v. Stability AI / Authors Guild v. Meta·Anthropic·OpenAI

| | |
|:---|:---|
| **事实** | 艺术家/作家集体诉 AI 公司未经许可用其作品训练。 |
| **命题** | 双方论点与 NYT 案相似：开发者主张合理使用/只学统计模式；权利人主张完整复制+记忆复吐。**尚无终审共识。** |
| **用于** | Q2（说明法律不确定性）、Q3（AI 法律待解问题）。 |

## B6. 周艳明 v. 环球时报 (2012)｜中

| | |
|:---|:---|
| **事实** | 媒体报道中使用某封面照。 |
| **命题** | 不同传播目的、取用有限、未替代原许可市场 → 落入 **A.24 法定例外**。 |
| **用于** | Q2(b)（中国 limitations 封闭清单的实际适用）。 |

# 主题块 C · AI 作者身份与发明人 (Authorship & Inventorship)

## C1. Thaler v. Perlmutter (版权) / Thaler v. USPTO (专利)｜美 ★核心案

| | |
|:---|:---|
| **事实** | Thaler 用其 AI"Creativity Machine"/"DABUS"自主生成作品与发明，申请将 AI 列为作者/发明人。 |
| **命题** | **版权**：版权仅保护"人脑创造力之果"→ 否定 AI 作者；2025 指南要求人类贡献须**超过提示或小修**。**专利**：仅**自然人**可为发明人 → 驳回。 |
| **用于** | AI 作者身份题、AI 发明人题。**美国"否定"立场的代表。** |

## C2. 李昀锴 v. 刘元春 (北京互联网法院)｜中 ★核心案

| | |
|:---|:---|
| **事实** | 原告用 Stable Diffusion 输入提示词（含负面提示）+ 调参，生成一张女子图，被告未经许可使用。 |
| **命题** | 只要 AI 生成图体现人的**原创性智力投入**（提示设计、参数调整、选择判断）即可为**作品**受保护。中国**更宽松、个案判断**。 |
| **用于** | AI 作者身份题。**与 Thaler 形成中/美对比**（同一问题、相反结论）。 |

## C3. Monkey Selfie / Naruto 猴子自拍案｜美

| | |
|:---|:---|
| **事实** | 猕猴 Naruto 用摄影师 Slater 留置的相机拍下自拍。 |
| **命题** | 三步分析：① 摄影=受保护作品；② CL 要求**人类（自然人/公民）**作者→动物非作者；③ 须**智力创作**→动物凭本能非智力。Slater 是否作者**有争议**（缺创作意图）。 |
| **用于** | AI 作者身份题（"非人类创作者"类比 AI）、"人类作者门槛"。 |

## C4. DABUS (AI 发明人案)｜全球

| | |
|:---|:---|
| **事实** | DABUS AI 被称发明了食品容器 + 警示灯，全球多国申请将其列为发明人。 |
| **命题** | 现行法**仅承认人类**发明人，申请**多被驳回**（USPTO/EPO 一致）。AI 无法律人格→不能签文件/转让/被诉/获报酬/担责。 |
| **用于** | AI 发明人题。 |

## C5. Moderna (mRNA) 例

| | |
|:---|:---|
| **事实** | Moderna 用 AI/ML 做 mRNA 序列优化、蛋白结构预测、候选筛选，但专利**只列人类发明人**。 |
| **命题** | AI 视为**辅助工具**（如先进实验设备），关键决策由人作出 → 人类有重大贡献 → 可专利。 |
| **用于** | AI 发明人题（"AI 辅助 vs AI 发明"的正面例子）。 |

# 主题块 D · 隐私、数据保护与再识别 (Privacy & Re-identification)

## D1. Netflix Prize 案｜美 ★再识别标杆

| | |
|:---|:---|
| **事实** | Netflix 公开约 48 万用户"匿名"评分数据（随机ID+影片+评分+日期）。Narayanan & Shmatikov (2007) 用 IMDb 公开评分**重新识别**了用户。 |
| **命题** | **少量评分+日期即可唯一定位个人**。声称"匿名"≠真匿名，关键看**再识别风险**。 |
| **用于** | **Q4(c)**（"匿名化研究数据"抗辩）、匿名 vs 假名区分。 |

## D2. Clearview AI 案｜美/EU

| | |
|:---|:---|
| **事实** | 美国公司从社媒抓取约 **300 亿张**公开照片+元数据，建人脸识别库，卖给执法部门。在 EU 被 GDPR 起诉。 |
| **命题** | **GDPR 对非欧盟公司也适用**，只要活动涉及"监控欧盟境内个人行为"。Clearview 辩称仅抓公开图/非监控，DPA 不认同。三问：公开照片是个人数据吗？公开=同意吗？嵌入向量是个人数据吗？ |
| **用于** | Q4（GDPR 域外效力、人脸识别合法性）、隐私模块。 |

## D3. X 训练 Grok 案 (2024)｜EU

| | |
|:---|:---|
| **事实** | X 用欧盟用户**公开帖子**（含姓名、观点、信仰、位置等敏感数据）训练 LLM，用户未被清楚告知，用"默认开启"同意 + 主张正当利益。 |
| **命题** | noyb 投诉缺乏正当利益；爱尔兰 DPC 申请法院中止，X 同意暂停。DPA 间分歧（ICO/CNIL 支持正当利益、荷兰反对）→ **法律不确定性**。 |
| **用于** | Q4/隐私题（正当利益 vs 同意、跨境训练合法基础）、说明 AI 训练合法性争议。 |

## D4. OpenAI/ChatGPT (意大利 Garante) 案｜EU

| | |
|:---|:---|
| **事实** | 用户对话与支付信息**数据泄露**；为训练算法大规模收集存储个人数据。 |
| **命题** | "为训练算法而大规模收集存储个人数据"**无合法基础**；数据泄露暴露给他人。 |
| **用于** | Q4/隐私题（训练数据合法基础、数据安全义务）。 |

## D5. DeepSeek 案｜EU

| | |
|:---|:---|
| **事实** | DeepSeek 的**跨境数据传输**实践被指不符合 GDPR。 |
| **命题** | 跨境传输须满足充分性/SCCs/BCRs 等机制，否则违规。 |
| **用于** | Q4(a)（跨境数据传输合法性）。 |

## D6. 郭兵 v. 杭州野生动物世界 (2021)｜中

| | |
|:---|:---|
| **事实** | 季票持有者起诉动物园将入园验证从指纹改为强制人脸识别，并存储其人脸模板。 |
| **命题** | **未经同意和必要性论证，不得强制收集生物特征（敏感个人信息）**。 |
| **用于** | Q4/隐私题（PIPL 敏感数据、单独同意、必要性）、生物识别 AI。 |
