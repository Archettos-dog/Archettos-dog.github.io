## 1. 字符串 Strings
**(对应：17_Strings.pdf)**

### 1.1 String 的本质与不可变性 (immutability)
- **定义**：String 不是基本类型，是**对象 (object)**；字符串字面量用双引号界定。`java.lang.String` 自动被每个程序导入，无需手动 `import`。(讲义2页)
- **不可变 (immutable)**：String 对象一旦创建**不能被修改**，目的是**安全 (security)** 与**节省内存**。(讲义3页)
- **String Pool（字符串池）**：JVM 存放字符串字面量的内存区。
  - 若池中已存在相同值的 String，JVM **不创建副本**，而是把引用指向已有条目。(讲义3页)
  - **垃圾回收器 (Garbage Collector) 不清理 String Pool**。(讲义3页)
- **易错点**：`String s = "0"; for(int x=1;x<10;x++){ s = s + x; }` —— 共创建 **10 个** String 对象，最终 `s` 指向 `"0123456789"`。每次 `+` 都生成新对象。(讲义3页)
- **判据 · 普通对象 vs String 的引用行为**（高频考输出题）：(讲义4页)
  - 普通对象：`r2 = r1` 后两者指向同一对象，改 `r2` 也改 `r1` → 两行都打印 `Blinky`。
  - String：`s2 = s1; s2 = "Holmes";` —— `s2` 重新指向新字面量，`s1` 不变 → 打印 `Sherlock` / `Holmes`。
- **API 中不可变的类**：`String`, `Character`, `Integer` …（可变示例对比见 `Rectangle` 有 setter；不可变示例 `Colouring` 用 `tint()` 返回新对象）。(讲义5页)

### 1.2 String 类与构造方法
- `+` 是 Java 中**几乎唯一的运算符重载 (operator overloading)**，用于字符串拼接。(讲义6页)
- 索引从 **0** 到 **length()-1**。(讲义6页)
- **构造方法**：(讲义6页)
  ```java
  String s = "HelloWorld!";              // 字面量
  String s = new String("HelloWorld!");
  String s = new String();               // 空串
  char[] a = {'t','i','g','e','r','s'};
  String s = new String(a);              // "tigers"
  String s = new String(a, 1, 2);        // 从下标1取2个 → "ig"
  ```

- **易错点**：`equals()` 比较内容，`==` 比较引用；考试常考用哪个比较字符串内容（答案：`equals`）。(讲义8页)
- **典型例题**：`"bar:foo:bar".split("a")` → `["b", "r:foo:b", "r"]`（注意按 `a` 切，末尾空串处理）。(讲义10页)

### 1.4 可变字符串：StringBuffer 与 StringBuilder
- **用途**：处理**可变 (variable) 字符串**；String 用于常量字符串。(讲义12页)
- Java 用 **Unicode（每字符 2 字节）**，效率不高；StringBuffer 每次需重新分配空间，故 Java **预多分配 16 个字符**。(讲义12页)
- **判据 · 选择**：(讲义12-13页)
  - `StringBuffer`：**线程安全 (synchronised)**，旧 Java 使用。
  - `StringBuilder`（Java 5.0 起）：方法**不加 synchronised**，单线程 + 大量字符串操作时**效率更高**，推荐使用。
  ```java
  StringBuffer s = new StringBuffer();      // 默认
  StringBuffer s = new StringBuffer(20);    // 指定容量
  StringBuffer s = new StringBuffer("cat");
  ```
- **技巧**：程序里有大量字符串拼接/修改时，用 StringBuilder 而非 `+`。(讲义12页)

### 1.5 Character 包装类
- `Character` 是单个字符的**包装类 (Wrapper class)**，属 `java.lang`。(讲义14页)
- 常用静态方法：`isLetter(c)`, `isDigit(c)`, `isUpperCase(c)`, `isLowerCase(c)`, `isLetterOrDigit(c)`。(讲义14页)
- `charValue()` 取出包装的 char；`compareTo()` 返回字符码差值（如 `'c'.compareTo('f')` → -3）。(讲义14页)

### 1.6 StringTokenizer（切词，遗留类）
- **定义**：`java.util.StringTokenizer`，把字符串拆成 **token（标记）**；分隔符为 **delimiter（分隔符）**。(讲义15页)
- 默认分隔符：**空格、制表符、换行、回车**。(讲义15页)
- **构造方法**（无无参构造）：(讲义16页)
  ```java
  StringTokenizer(String s)
  StringTokenizer(String s, String delimiters)
  StringTokenizer(String s, String delimiters, boolean returnDelimiters)
  ```
- 常用方法：`countTokens()`, `hasMoreTokens()`, `nextToken()`。(讲义17页)
- **易错点 / 技巧**：StringTokenizer 是**遗留 (legacy) 类**，新代码应改用 `String.split()`；但要能读懂旧代码。(讲义15页)
- **典型例题**：`new StringTokenizer("abc,def,ghi")` → 默认分隔符不含逗号，`nextToken()` 输出整串 `abc,def,ghi`；若指定 `","` 为分隔符，则输出 `abc`。(讲义18页)

### 1.7 Scanner（Java 5.0）
- 相比 StringTokenizer（分隔符只能是单字符），`java.util.Scanner` 允许用**一个词 (word)** 作分隔符。(讲义19页)
- 用法：`useDelimiter(...)`, `hasNext()`, `next()`。(讲义19页)
- **其他用途**：(讲义20页)
  - 扫描基本类型：`nextInt()` 等。`new Scanner("1 10 100 1000")` 循环 `nextInt()` 求和 = 1111。
  - 读控制台：`new Scanner(System.in)`。
- **技巧 · 选择**：多个单字符分隔符 → 用 `String.split()`；用整个词作分隔符 → 用 `Scanner`。(讲义20页)

### 1.8 格式化输出 Format Specifier
- **语法**：`% [argument_number$] [flags] [width] [.precision] type`。(讲义21页)
- 类型：`%d` 十进制整数，`%f` 浮点，`%x` 十六进制，`%c` 字符，`%s` 字符串。(讲义21页)
- **典型例题**：`String.format("I have %,6.2f bugs", 12345.6789)` → `I have 12,345.68 bugs`（`,` 加千分位，`.2` 两位小数）。(讲义21页)
- `printf` vs `println`：`printf("%s %s has %d %s.\n", ...)` 用占位符；`println` 用 `+` 拼接。(讲义22页)
- 宽度/精度：`%15s` 右对齐占 15 列；`%,8.2f` 千分位+2位小数；`%n` 换行。(讲义23页)

## 2. 数字与 static/final/递归 Numbers
**(对应：18_Numbers.pdf)**

### 2.1 final 修饰符
- **定义**：`final` 用于**限制继承/修改**。(讲义2页)
  - `final` 变量：值不可改（如 `public final int topSpeed = 100;`）。
  - `final` 方法：不能被子类**重写 (override)**。
  - `final` 类：不能被**继承/扩展 (extend)**（如 `public final class Square`）。
- **判据 · final 变量初始化**：必须在**声明时**或在**构造方法中**初始化。(讲义15页)
- **易错点**：`final` 类 ≠ `abstract` 类，是相反概念。(讲义15页)

### 2.2 static（类变量 / 类方法）
- **定义**：`static` 成员属于**类**而非实例；类加载时创建，**所有实例共享同一份**。(讲义3-4页)
  - 无论有多少实例，类变量只有一份。
  - 像"类范围的全局变量"；类加载（而非建实例）时可用。
- **核心判据（高频）**：(讲义4, 12, 17页)
  - **static 方法只能引用 static 变量 / 调用 static 方法**，不能直接访问实例变量/方法。
  - 调用 static 方法用**类名**（`Math.max(10,20)`）；调用非 static 方法用**引用变量**（`myDog.catchBall()`）。
- **典型例题（计数器）**：(讲义5-6页)
  ```java
  public class Rectangle {
    private static int count = 0;   // 类变量
    public Rectangle(int w,int h){ ... count++; }
    public static int getCount(){ return count; }
  }
  // 未建实例即可：Rectangle.getCount() → 0；new 一个后 → 1
  ```
- **易错点（Practice Ex1/3）**：把 `getWidth()` 等访问实例变量 `this.width` 的方法写成 `static` → 编译错误（static 中不能用 `this`/实例变量）。(讲义11, 17页)
- **static 初始化块**：类加载时运行一次，用于初始化 static final 变量：(讲义13-14页)
  ```java
  public static final double BAR_SIGN;
  static { BAR_SIGN = Math.random(); }
  ```
  - 命名约定：static final 常量**全大写**。

### 2.3 static + final 组合 = 常量
- 仅 `static`：可声明"常量"但仍可被改（`Math.PI = 3.0f;` 合法 → 不安全）。(讲义7页)
- `static final`：真正常量，赋值会编译错误。(讲义8页)
  ```java
  public static final float PI = 3.141592f;
  ```

### 2.4 Math 类与方法
- `Math` 方法类似"全局方法"：只作用于参数，不依赖实例变量；`Math` **无实例变量、不能实例化**（**私有构造方法**，并非 abstract/interface）。(讲义9, 12页)
- 常用方法（多为**重载 overloaded**）：(讲义18页)
  - `Math.random()` → `[0.0, 1.0)` 的 double。`Math.random()*5.0` → `[0.0, 5.0)`。
  - `Math.abs(x)` 绝对值；`Math.round(x)` 四舍五入到最近整数（`round(-10.8f)` → -11）。
  - `Math.min(a,b)` / `Math.max(a,b)`。
- **典型例题**：`Math.round(-0.5)` → **0**，`Math.round(0.5)` → **1**（向上取最近整数，.5 进位）。(讲义30页)

### 2.5 Random 类
- `java.util.Random` 生成随机数：`nextFloat()`, `nextInt()` 等。需 `import java.util.Random;`。(讲义19页)

### 2.6 包装类 (Wrapper Classes) 与自动装箱
- **定义**：基本类型需当对象用时使用包装类；每个基本类型都有对应包装类，属 `java.lang`（无需 import）。(讲义21页)
  - 8 个：`Boolean, Character, Byte, Short, Integer, Long, Float, Double`（注意 `Integer/Character` 名字与基本类型不同）。
- 手动装/拆箱：(讲义21页)
  ```java
  int i = 10;
  Integer iW = new Integer(i);     // 装箱
  int u = iW.intValue();           // 拆箱
  ```
- **自动装箱 (Autoboxing，Java 5.0)**：基本类型 ↔ 包装对象自动转换。(讲义22页)
  - `ArrayList<Integer> list; list.add(3); int x = list.get(0);` 自动完成装/拆箱。
  - **易错点**：泛型不能用基本类型 → `ArrayList<int>` 非法，必须 `ArrayList<Integer>`。(讲义22页)
  - 适用场景：方法参数、返回值、布尔表达式、数值运算、赋值均可混用包装与基本类型。(讲义23-24页)

### 2.7 parse 方法与 Number 抽象类
- **parse 方法**：把 String 转基本类型。(讲义26页)
  ```java
  int i = Integer.parseInt("10");          // 10
  double d = Double.parseDouble("123.45"); // 123.45
  ```
  - **易错点**：`Integer.parseInt("ten")` 能编译但运行时抛 **NumberFormatException**。(讲义26页)
- **static import（Java 5.0）**：`import static java.lang.Math.*;` 后可直接 `sqrt(4.0)`；但会降低可读性。(讲义27页)
- **Number 抽象类**：所有包装类都是 `Number`（`java.lang`）的子类。(讲义28-29页)
  - 提供常量 `MIN_VALUE` / `MAX_VALUE`；进制转换如 `Integer.toHexString(181)`。

### 2.8 递归 Recursion
- **定义**：方法直接或间接**调用自身**。必须有**基准情形 (base case，停止条件)**。(讲义32页)
- 经典问题：阶乘 n!、斐波那契 (Fibonacci)、汉诺塔 (Tower of Hanoi)。(讲义32页)
- **算法思想**：基准情形直接返回；复杂情形拆成"会做的部分"+"递归调用的更简单子问题"。需防**无限递归 (infinite recursion)**。(讲义33页)
- **公式 · 阶乘**：`n! = n·(n-1)!`，`1! = 1, 0! = 1`。(讲义34页)
  ```java
  public long factorial(long n){
    if (n <= 1) return 1;              // base case
    else return n * factorial(n-1);   // recursive call
  }
  ```
- **判据 · 递归 vs 迭代 (Iteration)**：(讲义35页)
  - 递归：无需循环控制的重复；表达清晰，但有额外**内存/时间开销**（每次调用要为局部变量/参数分配栈空间）。
  - 迭代：通常**更高效**。
  - **技巧（规则）**：若迭代是显然解法就用迭代；担心性能就避免递归。商业软件通常少用递归。
- **典型例题（Practice Ex5）**：`mystery(int a,int b){ if(b==0) return 0; else return a + mystery(a,b-1); }` → 返回 **a·b**（`mystery(1,7)` = 7）。(讲义36页)

## 3. 异常处理 Exception Handling
**(对应：19_ExceptionHandling.pdf)**

### 3.1 错误与异常的概念
- 错误来源：实现错误、非法对象请求（如越界）、对象状态不一致、环境因素（错误 URL、网络中断）、文件处理。(讲义2页)
- 常见运行时错误：数组越界 → `ArrayIndexOutOfBoundsException`；除零 → `ArithmeticException`。(讲义3页)
- **定义**：Java 运行时检测到错误就**抛出异常 (throw an exception)**。**异常是一个对象**，向调用代码发出"异常情况发生"的信号。(讲义3页)

### 3.2 运行时错误处理机制
- Java 强制程序员**要么捕获 (catch) 运行时错误，要么声明不捕获**。五个关键字：(讲义4页)
  - 检测与处理：`try`, `catch`, `finally`
  - 声明与抛出：`throws`, `throw`
- 通过看 `throws` 关键字得知所调用方法**可能抛异常**。(讲义4页)
- **优点**：让潜在运行时问题在**编译期 (compile time)** 被注意到，比穷举测试更有效。(讲义4页)
- 异常是 `java.lang.Exception` 的子类对象；**方法抛出 → 总是抛回调用方 (caller)**。(讲义5页)

### 3.3 异常类层次 (Exception Hierarchy)
```
            Throwable
        getMessage() / printStackTrace()
                |
            Exception
          /     |        \
   IOException  ...   RuntimeException
                       /        \
          ClassCastException  NullPointerException
```
- `Throwable` 提供 `String getMessage()`、`void printStackTrace()`，用于不知如何恢复时。(讲义6页)
- **多态 (polymorphism)**：`Exception` 类型对象可以是其任意子类实例 → `catch(Exception e)` 可捕获所有子类。(讲义6页)

### 3.4 try / catch / finally
- **语法**：(讲义9页)
  ```java
  try {
    // 可能抛 E1...En 的代码
  }
  catch (E1 e1) { /* 处理 E1 */ }
  // ...
  catch (En en) { /* 处理 En */ }
  finally {
    // 收尾：关闭文件等（可选）
  }
  ```
- **执行规则（高频考输出）**：(讲义8页)
  - try 中某语句抛异常 → 跳到对应 catch；若无对应 catch，则该方法把异常继续抛出。
  - **finally 无论是否抛异常都会执行**（常用于关闭文件）。
- **易错点 · try creep**：try 中抛异常会"跳出"，导致后续局部变量可能未正确初始化。(讲义10页)
  ```java
  int foo;
  try { foo = getResults(); }
  catch(Exception e){ }
  int bar = foo;   // 错误：foo 可能未初始化
  // 解决：int foo = 0; 或把用到 foo 的代码也放进 try（即 try creep）
  ```
- **典型例题（Practice Ex1）**：try 中 statement2 抛异常 →(讲义22页)
  - statement3 **不执行**（被跳过）；
  - 异常未捕获 → statement4 **不执行**；
  - 异常被某 catch 捕获 → statement4 **执行**。

### 3.5 throw vs throws
- **判据（核心区别）**：(讲义11-13页)
  - `throw`：**真正抛出**一个异常对象 → `throw new Exception("bad filename");`
  - `throws`：在方法签名上**声明**该方法可能抛出异常 → `public void m() throws Exception`
- 不想自己 catch 时，用 `throws` 声明，让调用方处理。(讲义13页)
- Javadoc 标注：`@throws ExceptionType reason`。(讲义13页)

### 3.6 自定义异常 (Custom Exception)
- 必须**继承 `Exception` 类**。(讲义14页)
  ```java
  public class InvalidDateException extends Exception {
    public InvalidDateException(){
      super("Invalid date: please try again ...");  // 调父类构造方法
    }
  }
  ```
- **典型例题（MyDate）**：`setDate()` 中对非法 year/month/day `throw new InvalidDateException()`；构造方法与 `setDate` 都 `throws InvalidDateException`。(讲义16-18页)
  - 不 catch（`main` 声明 throws）→ 程序崩溃打印栈轨迹。
  - catch 处理 → 打印 `e.getMessage()`，且 `finally` 总会执行。(讲义18页)

### 3.7 栈轨迹 (Stack Trace)
- 未捕获异常时 JVM 打印异常类型、信息和发生位置。(讲义19页)
  ```
  Exception in thread "main" java.lang.ArithmeticException: / by zero
      at PrintCalendar.daysInMonth(PrintCalendar.java:121)
      at PrintCalendar.main(PrintCalendar.java:42)
  ```
  - 读法：异常类型 `ArithmeticException`（属 `java.lang`），发生在 `daysInMonth()` 第 121 行，由 `main()` 第 42 行调用。

### 3.8 受检 vs 非受检异常（高频判据）
| 类型 | 受检异常 (Checked) | 非受检异常 (Unchecked) |
|---|---|---|
| 父类 | `Exception` 的子类 | `RuntimeException` 的子类 |
| 用于 | **可预料**的失败 | **不可预料**的失败 |
| 恢复 | 可能恢复 | 不太可能恢复 |
| 编译器 | **强制** catch 或 throws | **不强制** |

(讲义21-23页)
- 例子：`IOException`, `InterruptedException` 是受检；`NullPointerException`, `ClassCastException`, `ArrayStoreException`, `IndexOutOfBoundsException`, `NegativeArraySizeException`, `ArithmeticException` 是运行时（非受检）异常。(讲义23页)
- 运行时异常不强制捕获的原因：发生太频繁，编译器检查成本太高；**理想做法是先检查输入前置条件 (pre-conditions)**。(讲义22页)
- **技巧**：尽量复用已有异常类型（如 `IllegalArgumentException`）；方法抛出的异常是其接口的一部分。(讲义23页)

## 4. 文件输入输出 File I/O
**(对应：20_FileIO.pdf)**

### 4.1 保存数据的两种方式
- 变量/数组/对象中的数据是**临时的**，程序结束即丢失；持久化需写入磁盘文件。(讲义2页)
- 两种方式：(讲义3页)
  - **序列化 (Serialisation)**：数据仅供生成它的 Java 程序使用（保存程序状态）。**本课程不涉及**。
  - **文件（如纯文本文件）**：数据需被其他程序使用（如 `.csv` 给 Excel 读）。

### 4.2 I/O 与流 (Streams)
- **定义**：I/O 即输入(读)/输出(写)；**流 (stream)** 是到数据源或目的地的连接，是从源流向目的的**字节序列 (sequence of bytes)**。(讲义4, 6页)
- 一个程序可同时管理多个流。(讲义6页)
- **读写三步骤**（必背）：(讲义7, 13页)
  1. 打开流 (Open) —— 创建合适的流类实例。
  2. 使用流 (Use) —— 循环读/写。
  3. 关闭流 (Close) —— `close()`。
- **两大类流**：(讲义8页)
  - **字节流 (byte streams)**：机器格式数据 → `InputStream` / `OutputStream`。
  - **字符流 (character streams)**：人类可读文本 → `Reader` / `Writer`。
  - 文本文件 (text file) 人类可读（如 `.java`）；二进制文件 (binary file) 供程序读、更高效（如 `.class`）。**本课程不涉及二进制 I/O**。

### 4.3 java.io.File 类
- **定义**：`java.io.File` 是文件名+目录路径的**包装类**，表示抽象路径名；隐藏文件系统差异。(讲义10页)
- **易错点**：文件不存在也**不抛异常**；构造 File 对象**不会**自动创建磁盘文件。(讲义10, 22页)
- 完整文件名 = 路径 (path) + 文件名 (name)。(讲义10页)
- 常用构造方法/方法：(讲义11页)
  ```java
  File(String pathname)
  boolean exists() / isDirectory() / isFile()
  boolean canRead() / canWrite()
  boolean delete()
  String getAbsolutePath()
  boolean renameTo(File dest)
  long length()        // 字节数
  String[] list()      // 目录下文件列表
  boolean mkdir()
  ```
  - 注：`java.io.File`（Java SE6），Java SE7 起用 `java.nio.file.Path`。
- **示例**：`new File("Examples\\badger.jpg")` 配 `exists()`, `canRead()`, `getAbsolutePath()`, `getName()`, `getPath()`。(讲义12页)

### 4.4 读写文本文件的类
- **读**：`FileReader`（表示文件 + 字符数据） + `BufferedReader`（提高效率、提供 `readLine()` 等方法）。(讲义14页)
- **写**：`FileWriter`（方法有限） + `BufferedWriter`（提高效率、提供有用方法）。(讲义14页)
- **判据 · FileReader vs FileWriter**：(讲义15页)
  - `FileReader`：文件不存在 → 抛 `FileNotFoundException`。
  - `FileWriter`：文件不存在 → **自动创建新文件**；构造方法可加 `boolean append` 控制追加。
  ```java
  FileReader(String filename) / FileReader(File file)
  int read() / int read(char[] cbuf) / void close()
  
  FileWriter(String filename) / FileWriter(String filename, boolean append)
  void write(int c) / write(char[]) / write(String) / void close()
  ```

### 4.5 典型读写代码模板（必背 + 高频考）
- **读一行**：(讲义16页)
  ```java
  try {
    FileReader fr = new FileReader(fileName);
    BufferedReader br = new BufferedReader(fr);
    contents = br.readLine();
    br.close(); fr.close();
  } catch (IOException e) {
    System.out.println("Errors occured"); System.exit(1);
  }
  ```
  - **易错点**："偷懒"地只 catch `IOException`，实际可能抛 `FileNotFoundException` 和 `IOException` 两种。(讲义16页)
- **读多行**：用 `while (oneLine != null) { ...; oneLine = br.readLine(); }`。(讲义17页)
- **读数字并处理**：`sum += Integer.parseInt(oneLine);`（结合 parse 方法）。(讲义18页)
- **写字符串**：`FileWriter` + `BufferedWriter`，`bw.write(contents); bw.close(); fw.close();`。(讲义19页)
- **技巧**：先关 Buffered 再关底层流；文件 I/O 会抛大量异常，必须放 try/catch。(讲义13, 19页)
- **典型例题（Practice Ex1）**：(讲义20页)
  - `new FileReader(file)` 能否编译？—— 需处理 `FileNotFoundException`（受检异常）。
  - 构造 File 对象**不会**自动建磁盘文件。
  - 确保已写数据刷入磁盘且文件保持打开的方法 → `flush()`。
  - `new FileWriter("myFile.txt")` → 创建（或覆盖）该文件的写入流。

## 5. 集合与排序 Collections & Sorting
**(对应：21_CollectionsAndSorting.pdf)**

### 5.1 Java 集合框架 (Java Collections Framework)
- **定义**：Collection 是"把多个元素组织成单一单元的对象"，可存储/检索/操作数据；位于 `java.util`。(讲义2页)
- 三大核心接口：(讲义3页)
  - **Set**：**无重复**元素，建模数学集合。
  - **List**：**有序**集合（序列），可按位置访问、**允许重复**。
  - **Map**：键→值映射，**键不重复**，每个键至多映射一个值。
- **判据 · 如何选集合**：固定 vs 动态大小、是否有自然顺序、插删位置、查找速度、随机 vs 顺序访问、是否需键值对。(讲义4页)

### 5.2 ArrayList（数组 vs ArrayList）
- `ArrayList` = 可增长/缩小的数组。(讲义5页)
  ```java
  String[] arr = new String[6];              // 数组：建时须知大小
  ArrayList<String> list = new ArrayList<>(); // 无需指定大小
  arr[4] = b;        // 须指定索引
  list.add(b);       // 直接添加
  ```

### 5.3 Map 与 HashMap
- `HashMap` 实现 `Map`，高效定位/插入/删除；**条目无序 (not ordered)**。(讲义6页)
  ```java
  Map<String,String> m = new HashMap<>();
  m.put("cat","Meow");
  String v = m.get("dog");   // 取值
  ```

### 5.4 Enumeration 与 Iterator
- `Enumeration`：Java 2 之前的遍历工具，已被 `Iterator` 取代。(讲义7页)
- **Iterator（迭代器）**：标准遍历方式。(讲义8页)
  ```java
  for (Iterator<String> it = alist.iterator(); it.hasNext(); ){
    String s = it.next();   // 泛型无需向下转型 (downcasting)
  }
  ```

### 5.5 二维数组 (2D Arrays)
- Java 把 2D 数组存为"数组的数组"。(讲义9页)
  ```java
  int[][] nums = new int[5][4];
  nums = new int[][];   // 非法：必须指定第一维
  nums = new int[5][];  // 合法：第二维可省
  ```
- **易错点**：声明 2D 数组**必须指定第一维**，第二维可后定。数组**不属于** Collections 框架。(讲义9页)
- **典型例题**：`char[6][6]` 用 `(i==j)||(i==0)||(i==5)` 画出对角线+首尾行的 `*` 图案；2D ArrayList 用 `ArrayList<ArrayList<Integer>>` 嵌套，`topList.get(i).add(...)`。(讲义10-11页)

### 5.6 排序算法 (Sorting Algorithms)
- **选择排序 (Selection sort)**：每次找最大放到末尾，重复。(讲义12页)
- **插入排序 (Insertion sort)**：反复把一个未排序元素插入到已排序子列的正确位置。(讲义12页)
- **冒泡排序 (Bubble / Sinking sort)**：多趟扫描，比较相邻对，逆序则交换。(讲义13页)
  ```java
  boolean changed = true;
  do {
    changed = false;
    for (int j=0; j < list.length-1; j++){
      if (list[j] > list[j+1]) {
        double temp=list[j]; list[j]=list[j+1]; list[j+1]=temp;
        changed = true;
      }
    }
  } while (changed);
  ```
  - **技巧**：用 `changed` 标志位，一趟无交换即提前结束。(讲义13-16页)

### 5.7 Comparable 接口（对象比较与排序）
- 比较对象的两种方式：实现 `Comparable` 接口，或用 `Comparator` 对象（**Comparator 本课不涉及**）。(讲义17页)
- **判据 · Comparable**：(讲义17-18页)
  - 实现 `Comparable` 的对象按**自然顺序 (natural order)** 排序。
  - 接口只含一个方法 `compareTo()` → 只能提供**一种**自然排序；要多种排序须用 `Comparator`。
  - `compareTo()` 返回：`0`（相等）/ `<0`（小于）/ `>0`（大于）。
- **典型例题（Employee 按薪资排序）**：(讲义19-20页)
  ```java
  public class Employee implements Comparable<Employee> {
    double salary;
    public int compareTo(Employee o){
      if (this.salary == o.salary) return 0;
      else if (this.salary > o.salary) return 1;
      else return -1;
    }
  }
  // 使用：Collections.sort(list);  // 依 compareTo 排序
  ```
  - **技巧**：要让自定义类对象可被 `Collections.sort()` 排序，必须 `implements Comparable` 并实现 `compareTo()`。

## 6. 跨主题高频考点速记

### 6.1 易混概念对比表
| 概念 A | 概念 B | 关键区别 |
|---|---|---|
| `String` | `StringBuilder/Buffer` | 不可变常量 vs 可变；大量拼接用后者 |
| `StringBuffer` | `StringBuilder` | 线程安全(慢) vs 非同步(快, Java5+) |
| `==` | `equals()` | 比引用 vs 比内容（字符串内容比较用 equals） |
| `static` 方法 | 实例方法 | 类名调用、只能访 static 成员 vs 引用调用 |
| `static` | `final` | 共享一份 vs 不可改；组合得常量 |
| `throw` | `throws` | 抛出对象 vs 声明可能抛出 |
| 受检异常 | 非受检异常 | Exception 子类强制处理 vs RuntimeException 不强制 |
| `FileReader` | `FileWriter` | 文件不存在抛异常 vs 自动创建 |
| 数组 | `ArrayList` | 固定大小 vs 动态、非框架 vs 框架 |
| `Set` | `List` | 无重复无序 vs 有序可重复 |
| 递归 | 迭代 | 清晰但开销大 vs 通常更高效 |

### 6.3 必背代码骨架

### 6.4 高频陷阱清单

- 2D 数组必须指定第一维。(Collections 9页)
- `Math.round(0.5)=1`，`Math.round(-0.5)=0`。(Numbers 30页)
- 泛型不能用基本类型：`ArrayList<int>` 非法。(Numbers 22页)
