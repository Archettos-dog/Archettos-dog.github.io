## 1. 课件 23 · Python OOP 概念：Java → Python 翻译

### 1.1 大局观（定义 / 对比）
- Python 创建于 1991 年，设计哲学：**可读性优先（readability counts）**，"应只有一种显而易见的做法"（The Zen of Python） `(23 p4)`。
- Java 与 Python 都编译成字节码（bytecode）：Java → `.class`，Python → `.pyc`；都是面向对象 `(23 p6)`。
- **关键区别**：Python 是**动态类型（dynamic typing）**，无需声明变量类型 `(23 p6)`。
- **一切皆对象（everything is an object）**：连 `int`、`bool` 这类在 Java 里是基本类型（primitive）的，在 Python 里都是对象 `(23 p7)`。
- 没有 `public static void main(String[] args)`；代码从上到下执行 `(23 p7)`。

### 1.2 数据类型对照（必背表）`(23 p7)`
| 类别 | Java | Python |
|------|------|--------|
| 整数 | `int, long, short, byte` | `int` |
| 浮点 | `float, double` | `float` |
| 字符/串 | `char, String` | `str` |
| 布尔 | `boolean`（基本类型） | `bool`（对象） |
| 空值 | `null` | `None` |
| 列表/数组 | `int[]` 或 `ArrayList` | `list` |
| 映射 | `HashMap<K,V>` | `dict` |

### 1.3 代码排版：花括号 vs 缩进 `(23 p8-9)`
- Java：靠花括号 `{}` 和分号 `;`。
- Python：仅靠**缩进（indentation，通常 4 空格）**和换行；类/方法头以**冒号 `:`** 结尾。

```python
# Python
if x > 0:
    print("Positive")
```

### 1.4 集合（Collections）`(23 p10-12)`
- `list` `[ ]`：有序、可变（mutable）序列，自动扩容。
- `dict` `{key:value}`：键值对，直接 `d["Age"]` 访问，**无需 `put()/get()`**。
- `set` `{ }`：无序、元素唯一，自动去重。
- 成员测试（membership）：用 **`in`** 关键字，如 `"item" in my_set`。
- Python 集合**不强类型**，可装任意对象类型。
- ⚠️ **易错点** `(23 p12)`：
  - `another_set = set()` → 空**集合**
  - `oneMore_set = {}` → 空**字典**（不是空集合！）

> 典型练习 `(23 p13)`：建字典 `student_data`，给键 `"grades"` 加 3 个成绩列表，建唯一科目 set，用 `sum()/len()` 算平均。

### 1.5 类定义与构造器 `(23 p14)`
- Java：构造器同类名 + 隐含 `this`。
- Python：用 **`__init__`** 方法 + 显式 **`self`**。
- `pass` 是空语句：占位、不报错。

```python
class Car:
    def __init__(self):
        pass
```

### 1.6 运行时动态属性 `(23 p16)`
- Java：所有字段（field）须编译前声明。
- Python：属性可在运行时动态附加；对象本质是键值字典（hash map）。

```python
my_car = Car()
my_car.color = "Red"   # 运行时凭空创建！
```

### 1.7 访问修饰符与命名约定 `(23 p17)`
- Java：编译器强制 `public/private/protected`。
- Python：**无强制**，全部技术上 public，靠命名约定：
  - `_variable` → "protected"（内部使用）
  - `__variable` → "private"

### 1.8 没有重载，用默认参数 `(23 p18)`
- Python **不支持方法重载（method overloading）**；同名方法后者覆盖前者。
- 解决：默认参数 + 关键字参数。

```python
def greet(self, name, greeting="Hello"):
    print(f"{greeting}, {name}")
# greet("Alice") 或 greet("Alice", "Hi")
```

### 1.9 静态 vs 动态类型 + 类型提示 `(23 p20-21)`
| 特性 | Java（静态） | Python（动态） |
|------|------|------|
| 声明 | `int x = 5;` | `x = 5` |
| 检查时机 | 编译期 | 运行期 |
| 重新赋值不同类型 | `x="Hello"` 报错 | `x="Hello"` 允许 |

- **类型提示（type hints，Python 3.5 引入）**：是"提示"非"规则"，IDE 会警告但运行不强制。

```python
def process_data(data: list) -> bool:
    return len(data) > 0
```

### 1.10 Python 软件设计利弊 `(23 p23)`
- 优点：快速原型（rapid prototyping）、开发快、标准库大、代码量少。
- 缺点：执行慢（解释执行 + GIL）；测试不足时动态类型易引发运行时错误。

> **本课件作业**（高频考型）`(23 p26)`：把 Java `BankAccount` 改写为 Python：① 用 `__init__`；② 全程 `self`；③ `_balance` 命名约定；④ 两个 `deposit` 合并为带默认参数的一个；⑤ 类外把整型变量改成字符串演示动态类型。

## 2. 课件 24 · 继承、抽象类与多态

### 2.1 类关系 + Python 继承的双重含义 `(24 p2-5)`
- 两种关系：**聚合 aggregation（has-a）**、**继承 inheritance（is-a）**。
- Python 继承同样表达 **is-a**（子类是父类的更具体版本）。
- **关键扩展**：Python 中继承还定义了**运行时查找属性的路径（runtime lookup）**——访问 `obj.method()` 时 Python 沿继承链**从下往上**搜索，不是编译期按类型确定 `(24 p7)`。

```python
class Animal:
    def speak(self):
        print("Animal makes a sound")
class Dog(Animal):
    pass
d = Dog(); d.speak()   # 沿链向上找到 Animal.speak
```

### 2.2 重写 Overriding：First Match Wins `(24 p11-12)`
- 多个类定义同名方法时，Python **不合并**，沿查找链选**第一个匹配**就**立即停止**。
- 重写不删除父方法，只是改变"搜索停在哪里"。

### 2.3 `super()`：继续查找链 `(24 p14-16)`
- 重写会切断链；若想既加子类行为又复用父类行为，用 **`super()`**。
- `super()` 让 Python 从查找链的**下一个类**继续，而非停在第一个匹配。
- 对比 Java：Java 里 `super()` 通常解释为"直接访问父类"；Python 里解释为"继续查找链"。

```python
class PizzaRobot(Chef):
    def work(self):
        super().work()          # 继续向上执行 Chef.work
        print("Robot makes pizza")
```

### 2.4 多态 Polymorphism `(24 p18-21)`
- 定义：用**一个操作**作用于**不同类型**的对象，操作含义取决于具体对象。
- Java：基于**类型（type）**；Python：基于**行为 / 查找（behaviour / lookup）**。
- 经典写法（一个循环、多种行为）：

```python
company = [Employee(), Engineer(), Manager()]
for emp in company:
    emp.computeSalary()   # 每个对象查找结果不同 → 行为不同
```

### 2.5 鸭子类型 Duck Typing `(24 p22-26)`
- 多态不一定来自继承。Python 里对象**无需共享父类 / 同一继承树**，只要**支持所需操作**即可。
- "如果它走起来像鸭子、叫起来像鸭子，它就是鸭子"——只看行为，不看声明类型。
- Java：必须显式 `extends`/`implements`，更严格、更安全。
- Python：更灵活，但**缺失行为的错误会晚到运行时才暴露**。

```python
team = [Chef(), PizzaRobot(), Server()]
for member in team:
    member.work()   # 三者无共同父类，只要都有 work() 即可
```

- ⚠️ **陷阱** `(24 p26)`：若 `Intern` 类只有 `pass`（没有 `work()`），循环到它时报 `AttributeError`。→ 引出抽象类。

### 2.6 抽象类 Abstract Class `(24 p27-31)`
- 目的：把错误检测从**方法调用时**提前到**对象创建时**——禁止创建"模板对象"，强制子类实现关键方法。
- Java：`abstract` 关键字，编译器禁止实例化抽象类。
- Python：用内置 **`abc` 模块**，方法上加 **`@abstractmethod`**。

```python
from abc import ABC, abstractmethod
class Worker(ABC):
    @abstractmethod
    def work(self):
        pass
```

- 行为 `(24 p30)`：
  - `Worker()` → **`TypeError: Can't instantiate abstract class`**
  - 子类未实现 `work()`（如 `Intern`）→ 创建时报错
  - 子类实现了 `work()`（如 `Chef`）→ 正确，可实例化
- **Java vs Python 抽象类** `(24 p31)`：Java 是类型系统一部分、编译期检查、强调类型正确；Python 是运行系统一部分、对象创建时检查、强调行为正确、是**可选**设计工具。

### 2.7 组合 vs 继承 Composition vs Inheritance `(24 p32-35)`
| | 继承 Inheritance | 组合 Composition |
|---|---|---|
| 关系 | is-a（类型关系） | has-a（整体-部分） |
| 行为来源 | 类层次 | 被包含对象的委托（delegation） |
| 耦合 | 紧耦合 | 组件独立、可复用 |

```python
class PizzaShop:            # has-a：组合
    def __init__(self):
        self.chef = Chef()
        self.oven = Oven()
    def make_pizza(self):
        self.chef.cook(); self.oven.bake()
```

- **何时用** `(24 p35)`：真正 is-a / 要特化 / 共享逻辑 → 继承；由组件构成 / 要灵活复用 / 关系会变 → 组合。Python 常**偏好组合**（避免深继承链、模块化、天然配合 duck typing）。
- 📌 这正是复习课真题 5 的考点（见 §7）。

## 3. 课件 25A · Pythonic 接口：`@property` 与魔术方法

### 3.1 封装：Java 严格 vs Python 约定 `(25A p3)`
- Java：字段 private，靠 public getter/setter；`getName()/setName()`。
- Python：属性默认 public，`_variable` 仅约定内部使用；**只在需要逻辑时才写 getter/setter**，不"以防万一"全写。

### 3.2 `@property`：把方法当属性访问 `(25A p4)`
- 实现**统一访问原则（uniform access principle）**：调用方不关心访问的是字段还是方法。

```python
class Product:
    def __init__(self, price):
        self._price = price      # 内部存储
    @property
    def price(self):
        return f"${self._price:.2f}"   # 访问 product.price 即调用此法
```

### 3.3 `.setter`：加验证逻辑 `(25A p6)`
- 语法 `@属性名.setter`，是写 `if` 验证的地方。

```python
@price.setter
def price(self, value):
    if value < 0:
        raise ValueError("Price cannot be negative!")
    self._price = value
```

### 3.4 `__str__` vs `__repr__` `(25A p8)`
| | `__str__` | `__repr__` |
|---|---|---|
| 目标 | 可读性（readability），给用户 | 无歧义，给开发者/调试 |
| 被谁调用 | `print()`, `str()` | 解释器、`repr()` |

- 对应 Java 的 `toString()`。

```python
def __repr__(self):
    return f"Product(price={self._price})"
def __str__(self):
    return f"A product costing {self.price}"
```

- **只读属性（read-only）**：只定义 `@property` 不定义 setter，外部赋值会触发 `AttributeError` `(25A p12)`。

> 作业 `(25A p11)`：把 Java `Car` 的 `get_speed/set_speed` 合并为一个 `@property speed`，并限制速度 ≤ 120 km/h。

## 4. 课件 25B · 数据建模：`@dataclass` 与富比较

### 4.1 痛点 `(25B p3)`
- Java POJO（Plain Old Java Object）持 3 个字段需 ~50 行机械代码（字段+构造器+6 个 getter/setter + `equals/hashCode/toString`）。
- Python 普通 `__init__` 较好但仍重复，且要自己写 `__repr__`、`__eq__`。

### 4.2 `@dataclass` `(25B p4)`
- 自动注入 **`__init__`、`__repr__`、`__eq__`**。
- **必须写类型提示**才能识别字段（但运行时不强制类型）。

```python
from dataclasses import dataclass
@dataclass
class User:
    user_id: int
    name: str
    email: str
```

### 4.3 相等性测试 `(25B p7)`
- Java：`==` 比身份（identity），`equals()` 比值。
- `@dataclass` 自动重写 `__eq__`，使 `==` **按字段顺序逐个比值**。

### 4.4 不可变 `frozen=True` `(25B p8)`
- 等价 Java 的 `final`。给字段重新赋值 → **`FrozenInstanceError`**。
- `@dataclass(frozen=True)`。

### 4.5 ⭐ 可变默认参数问题（mutable default）`(25B p10)`
- **错误**：`members: list = []` —— 默认参数在类定义时**只求值一次**，所有实例**共享同一个列表**。
- **正确**：`field(default_factory=list)` —— 每个新实例都新建一个 `list()`。

```python
from dataclasses import dataclass, field
@dataclass
class Team:
    name: str
    members: list = field(default_factory=list)
```

### 4.6 排序：富比较（rich comparison）`(25B p12)`
- Java：`implements Comparable<T>` + 重写 `compareTo()`。
- Python：实现 `__lt__`、`__gt__` 等魔术方法；`@dataclass` 捷径 **`order=True`**。
- `order=True` 按**字段定义顺序**比较：先比第一个字段，相等再比下一个。

```python
@dataclass(order=True)
class Employee:
    level: int    # 主排序键
    name: str     # 次排序键
# sorted(my_list) 即可排序
```

- 进阶 `(25B p15)`：`@dataclass` 可继承；`Manager` 用 **`__post_init__`** 在初始化后做校验（如 `team_size` 不能为负）。

### 4.7 本课件汇总记忆 `(25B p14)`
`@dataclass` 替代 `__init__/__repr__/__eq__`；类型提示是文档非约束；`frozen=True`≈`final`；`default_factory` 修可变默认；`order=True` 自动富比较。

## 5. 课件 25C · OO 工具：`@classmethod` / `@staticmethod` / `__call__`

### 5.1 单构造器限制 `(25C p3)`
- Java：可定义多个不同签名的构造器（重载）。
- Python：`__init__` 是唯一初始化器；写两个后者覆盖前者。→ 如何从不同数据格式建对象？

### 5.2 `@classmethod`：替代构造器 / 工厂方法 `(25C p4-6)`
- 把方法绑定到**类本身**，第一个参数自动是类对象，约定名 **`cls`**（非 `self`）。
- 用作**工厂方法（factory method）/ 替代构造器**。

```python
class Date:
    def __init__(self, day, month, year):
        self.day, self.month, self.year = day, month, year
    @classmethod
    def from_string(cls, date_str):
        day, month, year = map(int, date_str.split("-"))
        return cls(day, month, year)   # 用 cls 而非 Date，子类友好
```

- 例 2：温度类 `from_fahrenheit(cls, f)`，公式 **C = (F − 32) × 5/9** `(25C p6)`。

### 5.3 `@staticmethod` `(25C p7)`
- 功能等同 Java 的静态方法：既不取 `self` 也不取 `cls`，只是逻辑上属于该类、放进类命名空间的普通函数。
- 类加载时即载入，不依赖实例。用于校验、独立数学计算。

### 5.4 何时用哪个（必背对照）`(25C p8)`
| | `@classmethod` | `@staticmethod` |
|---|---|---|
| 第一参数 | `cls`（类本身） | 无（像普通函数） |
| 能力 | 可改类状态、可调 `cls()` | 不能访问类/实例状态 |
| 用途 | 工厂方法、替代构造器 | 校验、独立数学 |
| 比喻 | 建筑师（architect） | 工具箱（toolbox） |

> 口诀：**方法需要知道"是哪个类"调用的 → 用 `@classmethod`**。

### 5.5 `cls` vs `self` `(25C p10)`
- `self`：指向内存中**具体对象**（≈ Java 的 `this`）。
- `cls`：指向**类定义本身**（≈ Java 的 `ClassName.class`）。
- 二者只是命名约定，Python 不强制用这两个词。

### 5.6 `__call__`：让对象可调用 `(25C p11)`
- 实现 `__call__(self, ...)` 后，实例可像函数一样调用 `my_object()`。
- Java 里要传递动作得用 `Runnable` 接口或 lambda。

```python
class Counter:
    def __init__(self):
        self.count = 0
    def __call__(self):
        self.count += 1
        return self.count
increment = Counter()
print(increment())   # 1
print(increment())   # 2
```

> 进阶 `(25C p15)`：`from_file` 返回 `cls(content)` 而非 `Document(content)`，使 `PDFdocument.from_file(...)` 返回 `PDFdocument` 实例——体现 `cls` 的多态构造作用。

## 6. 课件 26 · Python 数据处理

### 6.1 用原生结构表示数据 `(26 p3-7)`
- `list`（可变）/ `tuple`（不可变）；list 有序、可装任意类型、最通用。
- 二维表：每行一个 list，所有行再装进一个 list；访问 `data[行][列]`，索引从 **0** 开始。
- 局限：无列名、全靠位置、加列/换序/上千行时极易出错、不可扩展。

### 6.2 读 CSV：原生方式的不足 `(26 p9)`
```python
file = open("data.csv")
for line in file:
    print(line)     # 只是纯文本，不是结构化数据
```

### 6.3 三大科学库 `(26 p10)`
- **NumPy**：数值计算基础包（数组/向量/矩阵）。
- **Matplotlib**：高质量 2D 绘图。
- **pandas**：高性能、易用的数据结构。
- （另有 SciKit-Learn 机器学习、SciPy 数值算法。）

### 6.4 NumPy 数组 `(26 p11-13)`
- 安装 `pip install numpy`；导入 `import numpy as np`。
- 比 list 更高效、结构更清晰；**大小与类型需预先确定**，内存中紧凑存储。
- 访问仍是位置索引 `arr[0][1]`，**无列名**，不适合真实数据集。

```python
import numpy as np
arr = np.array([[1,23,88.5],[2,27,92.0],[3,22,75.5]])
print(arr[1][2])   # 92.0
```

### 6.5 pandas DataFrame `(26 p14-16)`
- 安装 `pip install pandas`；导入 `import pandas as pd`。
- **DataFrame**：结构化表格（有列标签 + 行索引）。
- **Series**：一维带标签数据；选一列 `df["Score"]` 返回 Series。
- 读 CSV：`pd.read_csv("data.csv")` 自动识别行列、首行作列名、自动生成行索引。

```python
df = pd.DataFrame({"Name":["Alice","Bob","Charlie"],

### 6.6 选择数据 `loc` vs `iloc`（高频考点）`(26 p17-20)`
- 选列：用列标签 `df["Score"]`。
- 选行：
  - **`loc`：基于标签（label-based）** —— `df.loc["b"]`、`df.loc[0]`（0 是标签）。
  - **`iloc`：基于位置（position-based）** —— `df.iloc[0]` 永远是第一行。
- **为何都要**：DataFrame 的索引可被改成非数字（如 `df.index=["a","b","c"]`），此时 `loc["a"]` 按标签、`iloc[0]` 按位置，结果可能不同。
- 单行结果以 **Series** 竖直显示（因为一行里各列类型不同）。

```
- ⚠️ 多条件用 **`&`(AND) / `|`(OR)**，每个条件加括号。

## 8. 终极速查（考前 5 分钟扫一遍）

**Java ↔ Python 关键映射**
- 构造器 → `__init__`；`this` → `self`；`{}` → 缩进；`null` → `None`。
- `private` 字段 → `_`/`__` 命名约定；getter/setter → `@property` + `.setter`。
- 方法重载 → 默认参数 / `@classmethod` 工厂方法。
- `toString()` → `__str__`/`__repr__`；`equals()` → `__eq__`（`@dataclass` 自动）。
- `Comparable/compareTo` → `__lt__…` / `@dataclass(order=True)`。
- `final` → `@dataclass(frozen=True)`；`static` 方法 → `@staticmethod`。
- 抽象类 `abstract` → `abc.ABC` + `@abstractmethod`；接口式多态 → duck typing。

**最易混淆点**
- `set()` 是空集合，`{}` 是空字典。
- `loc` 按标签，`iloc` 按位置。
- 重写 = 停止查找；`super()` = 继续查找。
- 可变默认参数要用 `field(default_factory=list)`。
- 抽象类错误在**对象创建时**报，不是方法调用时。
- `cls` 指类、`self` 指实例。
